Three steps

How to make a sticker cutline

Upload artwork that already has a shape

A transparent PNG gives the sharpest trace, because the tool follows the alpha channel. JPGs and WEBPs are traced as a full rectangle with a border.

Choose the offset and smoothing

The offset is the white border you keep outside the artwork. Smoothing removes pixel noise so the traced path is a clean curve instead of a staircase.

Download PNG and SVG

Send the PNG to whoever prints and the SVG to whoever cuts. Both files describe the same geometry, so the printed sticker and the cut path line up.

Reference

Cutline offsets, output specs and file formats

The exported PNG is a transparent raster file sized at 300 DPI for the finished long side you selected. The SVG keeps the same proportions but stores the outline as editable path geometry, which is what a vinyl cutter, laser or print shop actually needs.

What the SVG contains

  • Artwork — your image placed at its exact position, embedded at print resolution.
  • WhiteBorder — the filled shape that produces the border around the art.
  • Cutline — the stroked vector path a cutting machine follows. Offset, smooth or recolor it in any vector editor.

Better results in three minutes

  • Cut the background out first if you want a shaped sticker rather than a rectangle.
  • Use smoothing 3–6 for photographed artwork and 0–2 for clean vector-style art.
  • Always ask your printer for their preferred stroke colour and bleed before a production run.

Questions

Sticker cutline FAQ

What is a sticker cutline?

A cutline (or die-cut line) is the path a cutting machine follows to release a sticker from its backing sheet. It usually sits a small distance outside the artwork so the finished sticker keeps a white border.

Does this tool give me a real vector cutline?

Yes. The SVG download contains an editable path element traced from your image alpha channel, named Cutline, alongside the placed artwork and the white border. The PNG download is rasterised at 300 DPI.

Is my image uploaded to a server?

No. Uploaded artwork is decoded and traced in your own browser and is never sent to us. Downloads are generated on your device.

Which offset should I choose for a white border?

Two millimetres is a safe default for a clean white border. Use 1 mm for a tight border that risks cutter drift, and 3–5 mm for handheld scissors or a deliberately chunky sticker.

What size file should I send to a print shop?

Send the SVG for cutting and the 300 DPI PNG for printing. Confirm the final cut path and bleed with your printer, because machine calibration differs between cutters.
